1. 自衛隊の憲法明記に賛成
・自衛隊の存在が法律で明確にされていない現状を指摘し、自衛隊が国民を守るためには憲法にその存在を明記すべきと主張。ただし集団的自衛権の行使については慎重な姿勢。

2. 沖縄の基地負担軽減に取り組む意向
・沖縄の基地問題について、政府としての責任を認識し、基地負担の軽減に向けた取り組みを強調。特に普天間飛行場の移転の急務を訴え、沖縄県民の理解を得る努力を続けることが政府方針であると述べる。

3. 防衛大臣の資質についての批判
・現在の防衛大臣に対し、防衛に関する知識や説明能力が欠けていると批判。自衛隊の運営や情報発信の混乱を指摘し、適切な人材であるべきと主張。

4. 防衛出動と治安出動の明確化の必要性
・治安と防衛の境界が不明瞭であり、今後の状況に備えて法律を整備すべきと発言。特に領海内における警備の重要性を強調した。

5. 自衛隊の活動範囲の拡大の必要性
・国連の要請に応じた人道的活動など、国際的な任務に自衛隊を参加させるための法改正を提案し、自衛隊法に明確な任務規定を実装すべきと考えている。----------1. 自衛隊の憲法明記に賛成

2. 基地負担の軽減に取り組む意向
   - 沖縄の基地問題を重要視し、米軍基地の危険性を早急に取り除く努力を続ける意思を表明している。

3. 防衛大臣に対する批判
   - 現在の防衛大臣の知識や能力不足を指摘し、防衛省の適切な運営が日本国民を守る上で重要であると強調している。

4. 自衛隊法の改正に賛成
   - 自衛隊に国際的な任務をより効果的に遂行させるため、自衛隊法に新たな任務規定を設けるべきであると考えている。
