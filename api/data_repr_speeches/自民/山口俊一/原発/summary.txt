要約：
１．原発に対する一定の支持
・エネルギーの基本計画に整合性を持たせる中で原子力の役割を重視。原発の必要性を認めているが、慎重な姿勢も求めている。

２．過去の原発事故への懸念
・原発事故以来、国民の信頼が失われたことに言及。再発防止策として、燃料加工施設や研究炉に対する規制の強化が必要と愛院している。

３．技術者のモラルと緊張感の重要性
・原子力事業に従事する技術者の意識や緊張感の低下を真剣に懸念。これを改善しなければ、原子力政策の信頼性が損なわれると指摘。

４．国民の信頼回復の必要性
・事故により原子力政策への不信感が拡大していることを懸念。より安全で信頼性の高い政策を打ち出す必要があると主張。----------１．原発の必要性について一定の理解を示す
・原子力エネルギーの必要性や核リサイクルシステムの確立を肯定しているが、原発事故による国民の信頼喪失を懸念。

２．原子力安全対策の強化を提言
・過去の事故を受けて、燃料加工施設や研究炉などにも厳重な規制が必要だと訴え、技術者のモラルと緊張感の重要性を強調。

３．エネルギー基本計画との調和を重視
・原子力政策はエネルギー基本計画と整合性を保ちながら見直し、必要な取り組みを続けることが重要だと考えている。

４．事故による影響への配慮を強調
・原発事故がもたらした地域への生活物資の不足について言及し、事故の影響を受ける人々への配慮を欠かさない姿勢を見せている。----------1. 原発についての一定の理解と支持を示す
   - エネルギー基本計画における原子力の役割を重視し、原子力の研究開発や放射線利用の必要性に言及。

2. 原発事故の影響への懸念
   - 原発事故以降、化石燃料への依存が増している現状に対する懸念を表明し、原発の安全性についての議論が必要であると認識。

3. 規制の強化を求める
   - 過去の事故を踏まえて、原発だけでなく燃料加工施設や研究炉の規制強化が必要であると主張。

4. 国民信頼の回復が重要
   - 原子力に対する国民の信頼が失われないよう、核リサイクルシステムの確立などを通じて原子力政策を見直す必要性を訴える。
