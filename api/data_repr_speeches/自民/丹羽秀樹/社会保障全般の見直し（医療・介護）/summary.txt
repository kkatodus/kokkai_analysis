1. 日本型社会保障制度の維持に賛成
   ・高齢世代を支えるために現役世代が働く仕組みが重要であると強調。全ての世代が安心できる社会保障の構築を目指すべきと考えている。

2. 政府のリーダーシップの重要性を強調
   ・根本大臣のような社会保障政策の専門家が厚生労働行政を率いることが、日本にとって最良の選択だと認識。

3. 社会保障制度の見直しの必要性に言及
   ・高齢化社会に対応した社会保障制度の議論を進め、医学部新設などに関して関係府省庁と協力して必要な法令を検討する意向を示している。

4. 社会保障と税の一体改革の重要性を支持
   ・社会保障の充実と消費税増税が一体で進められるべきであり、その方向が正しいと考えている。

5. 国民への情報発信の重要性を指摘
   ・具体的な社会保障のビジョンを国民に示す必要があると感じており、成功するためには信頼が必要だと主張している。----------1. 社会保障制度の見直しに賛成
   - 高齢化社会を見据え、現役世代が支える仕組みの維持を重視し、社会保障と働き方改革の根本的な見直しが必要であると指摘。

2. 医療や介護に対する政策提案に積極的
   - 福祉制度の整備や医学部の新設について検討し、議論を進める方針を示しており、社会保障制度の質を向上させる姿勢が見られる。

3. 税と社会保障の一体改革を重要視
   - 社会保障と税の一体改革が経済の安定に必要であり、消費税増税の背景には税と社会保障の連携があると述べている。

4. 国民への具体的な説明の必要性を強調
   - 政府が社会保障の方向性について明確なビジョンを示し、国民に信を問う姿勢が重要であると主張。----------１．社会保障制度の見直しを支持
・日本型社会保障制度を維持するため、働き方改革や全世代が安心できる制度構築を進める必要性を強調。

２．医療・介護の制度改革の需要
・高齢化社会に対応するため、社会保障制度を見直し、医学部新設に関する協議を進める方針を述べる。

３．社会保障と税の一体改革を重視
・社会保障と税の改革が重要であるとの認識を示し、これを実行するための信頼を国民に求める必要性を指摘。

４．法案成立の優先順位に関心
・社会保障と税の改革について、特例公債法案との優先順位に疑問を呈し、議論が必要であると訴える。
