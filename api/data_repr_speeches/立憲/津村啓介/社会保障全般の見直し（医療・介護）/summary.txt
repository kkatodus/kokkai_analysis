１．社会保障制度の見直しに前向き
・医療保険制度の乱立を問題視し、統一した制度の必要性を指摘。労働者のライフスタイルに応じた柔軟な制度設計を支持。

２．悪質事業者への対策を重視
・社会保険料を適切に負担しない事業者による競争の歪みを懸念。法令遵守を促進する取り組みを強調。

３．社会保障協定の締結を急ぐべき
・在留邦人の利益を考慮し、国際的な社会保障協定の締結を早急に進める必要があると主張。政府の取り組みを促す。

４．番号制度の導入に期待
・新たな制度が社会保障制度や税制の改善につながる可能性を高く評価し、国民の理解と協力を求める。----------１．医療・介護制度の見直しを支持
・医療保険制度の過剰な複雑さを指摘し、制度の簡素化が必要と考えている。

２．日雇特例被保険者への支給期間通算化を提案
・保険料納付に関する公平性を重視し、日雇特例被保険者にも通算化を適用すべきとの意見。

３．社会保障制度の多様性を評価
・様々なライフスタイルに応じた社会保障制度の重要性を強調し、個別ニーズに応える制度の必要性を訴えている。

４．社会保障協定の締結の重要性を認識
・在留邦人の利益を守るため、社会保障協定の締結を早急に進めるべきと主張。----------1. 社会保障制度の見直しに賛成
   ・医療保険制度の乱立と不正競争の問題を指摘。現行制度の整理と効率化が必要だと主張。

2. 日雇特例被保険者の制度改善を提案
   ・支給期間の通算化を求め、保険料を納めている者としての扱いを平等にすべきだと考えている。

3. 働き方に応じた柔軟な社会保障制度を支持
   ・多様なライフスタイルに対応する制度の必要性を訴え、番号制度の導入に期待を寄せている。

4. 社会保障協定の締結を加速すべきとの意見
   ・在留邦人の利益を考慮し、政府の取り組みが遅れていると批判し、迅速な対応を求めている。
