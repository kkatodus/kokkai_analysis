1. 消費税の福祉目的税化を支持
・消費税を基礎年金や高齢者医療、介護の財源に限定すべきと主張し、これにより安定した社会保障の財政基盤を強化する必要があると述べている。

2. 減税の必要性を強調
・公共事業の積み増しではなく、行政改革による経費削減を通じて所得税や住民税の恒久的な減税を実施すべきとコメントし、これが景気対策になると述べている。

3. 物価スライドの見直し提案
・消費者物価指数に基づく物価スライドの適用が適切かどうか疑問を挙げ、税金や社会状況を考慮に入れた見直しを検討することが必要であると指摘している。

4. 社会保障制度の改革を要求
・現行の社会保険制度の破綻を指摘し、消費税が福祉目的以外に使われることを避けることで、負担の公平化や社会保障の基盤強化が必要であると強調している。----------１．消費税についての主張
・消費税を福祉目的税化し、基礎年金、高齢者医療、介護の財源として利用するべきと主張。これにより負担の公平化と社会保障の財政基盤を強化することを目指している。

２．減税に関する考え
・行政改革による経費削減を重視し、所得税や住民税の恒久的な減税を直ちに実施すべきだと考えている。これは景気対策にも繋がると主張。

３．物価高に対する意見
・物価スライドの基準として消費者物価指数のみを使うことに疑問を呈し、税金や社会状況を考慮に入れた指標を検討するべきと提言している。----------1. 消費税の福祉目的税化に賛成
   - 消費税の収入を基礎年金、高齢者医療、介護の専用財源として使うべきと主張。

2. 所得税・住民税の恒久減税を支持
   - 行政改革による経費削減を行い、その財源で減税を実施することが景気対策になると考えている。

3. 物価スライドの見直しを提案
   - 消費者物価指数のみで基準を設けるのは問題があるとし、より多様な社会状況を考慮に入れる必要があると主張。

4. 社会保障制度の破綻を懸念
   - 現在の社会保険制度が持続可能でないことを指摘し、国民生活のセーフティーネットの確立が必要と訴えている。
