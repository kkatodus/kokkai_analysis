1. 社会保障の充実が必要と考えている
・少子高齢化に対応するため、社会保障と税の一体改革を進める必要があると認識。国民の生活を守るための充実が重要。

2. 消費税の引き上げに慎重
・新たな負担を国民に強いる際には、無駄な経費の削減やサービスの維持が求められるとの立場。社会保障サービスの削減には反対。

3. 自治体の財政の厳しさを指摘
・地方の公共施設や社会保障関係の経費が増大する中、自治体が財政的に厳しくなっていることを危惧。これに対処するための明確な判断が必要。

4. 介護制度の変化に不安を表明
・介護保険制度の理念が自助中心に変わることに懸念、国が求めるサービスの質の低下を示唆。

5. 社会保障改革の進め方に疑問
・サービスの充実と効率化を同時に進めることが難しいと考えている。サービスの痛みを伴う削減には強く反対。

6. ボランティアの活用に懸念
・ボランティアをサービスの手段とすることが、権利としての介護が保障されていないとしての表れであると指摘。財源の逼迫を示唆し、不安を感じている。

7. 社会保障に対する政府の姿勢に批判
・経済財政諮問会議で社会保障が軽視されている状況に対して強い不満を示し、国民の期待に応える政策が求められると訴え。----------1. 社会保障全般の見直しを支持
   - 少子高齢化の進展に伴い、社会保障と税の一体改革が必要と強調し、財源の確保と効率的な運営を提案。

2. 消費税の引上げに賛成
   - 新たな負担を求める際は、社会保障の充実や無駄な経費の削減が必要であると指摘。

3. 社会保障給付の効率化への懸念
   - 効率化が進む中での給付削減が国民生活に負担をかけることを警戒し、その際には国民を犠牲にすることがあってはならないと強調。

4. 自助を重視する傾向への疑念
   - 介護保険制度の理念が変質し、サービスが縮小する中で自助が強調されることに不安を示す。

5. 新たな地域包括ケアシステムに注目
   - 社会保障の改革が進む中で、理想と現実の乖離や、服務の質が低下することへの懸念を表明。

6. 厚生労働委員会の重要性を強調

２．消費税の引上げは慎重に
・新たな負担が国民にかからないよう、無駄な経費を削減し、社会保障の充実が前提であるべき。

３．自治体の財政の硬直化を懸念
・社会保障や少子化対策への行政需要の高まりに対して、自治体が十分な財源を確保できていない状況を指摘。

４．効率化と給付の充実の同時進行に疑問
・効率化が進む中で、社会保障の充実とサービスの質を維持できるか不安を表明。

５．国民の生活を犠牲にする社会保障の削減に反対
・サービスカットの影響が国民生活に直結するため、徹底した見直しが必要であるとの立場。

６．自助中心の介護制度への変質を批判
・介護保険制度の理念が自助へと偏重している現状を憂い、サービスの権利が守られることの重要性を強調。 

７．地域包括ケアシステムの導入を重要視
・新たな社会保障システムの構築が必要であり、理想に向けた改革の進展を期待。
