要約：
１．社会保障制度の個人単位への移行を提唱
・企業単位の社会保障制度の限界を指摘し、個人単位の制度構築が必要との見解を示す。

２．介護労働者の賃金引き上げの必要性
・介護労働者の確保には賃金引き上げが急務であり、介護保険制度の見直しが不可欠と訴える。

３．介護保険制度の現状に対する危機感
・介護保険制度が本来の理念から後退していることを指摘し、緊急の見直しを求める。

４．保険料の負担増についての懸念
・高齢者に対する過度な保険料天引き政策を批判し、負担増の凍結や一般財源の活用による改善を提案。

５．社会保障制度改革の先送りに反対
・年金や医療制度、雇用などの社会保障改革を先延ばしにしてはいけないと強調し、問題解決のための議論を促進。----------1. 社会保障制度の見直しが必要との認識
   - 現行の企業単位の社会保障制度は限界に達しており、個人単位の制度構築が求められると考えている。

2. 介護保険制度の改革を重視
   - 介護労働者の賃金引き上げが急務であり、介護保険制度の見直しが重要であるとの立場を示している。

3. 介護の社会化に対する懸念
   - 介護保険制度の導入が当初の理念から後退しており、現状の給付状況に対して問題提起を行っている。

4. 財源に対する提案
   - 一般財源を介護保険に導入し、保険料や自己負担の増加を防ぐべきだと提案している。

5. 社会保障制度改革の先送りへの警鐘
   - 年金や医療制度の改革を先送りせず、早急に取り組むべきだと強調している。

6. 財務省の姿勢に対する批判
   - 社会保障費ばかりを問題視する財務省の態度を批判し、無駄遣いの改善が必要だと述べている。----------1. 社会保障の全般的な見直しに賛成
   ・現在の企業単位の社会保障制度は限界に達しており、個人単位の制度への移行が必要であると主張している。

2. 介護保険制度の見直しを強く支持
   ・介護労働者の賃金引き上げが急務であり、介護保険制度の改革が人材確保につながると考えている。

3. 介護制度の危機的状況を認識
   ・介護保険制度の現状は理念から後退しており、政府の対応が不十分であると批判している。

4. 財源の確保と保険料の負担軽減を求める
   ・一般財源を介護に導入し、保険料や自己負担の増加を抑えるべきと提言している。

5. 社会保障制度改革の先送りを避けるべき
   ・年金や医療制度の改革を急ぐ必要性を強調し、今後の議論を進めることを促している。
