1. 社会保障の見直しを提唱
・社会保障の中でも、医療や介護制度について具体的な権利拡大が不足していることを指摘。

2. 介護保険制度の重要性を強調
・高齢者福祉は介護保険制度に組み込まれているため、介護保険に基づいた制度設計が重要であると述べている。

3. 政策立案の必要性について言及
・社会保障政策は正確なデータに基づくべきで、そのための政策進捗の確認が重要であると主張。

4. 年金信頼回復への取り組み
・保険料の流用問題を指摘し、国民の年金制度への信頼を回復するためには全額国庫負担に戻すべきと提案。

5. 税制や優遇措置の見直しを示唆
・専業主婦家庭を前提とした税制優遇措置の見直しを考慮しつつ、女性の社会進出を促進するための労働環境整備が急務であると考えている。----------１．社会保障制度の見直しを提案
・社会福祉制度は児童、障害者、高齢者の三つがあり、高齢者福祉は介護保険制度に組み込まれていると指摘。

２．介護保険の位置付けを強調
・保険料を払うことで受給できる権利の拡大が必要であり、介護保険制度を重視するべきと発言。

３．政策の基盤としてのデータの重要性を強調
・政策立案には精緻なデータが必要であり、進捗を確認するための情報が重要であると述べる。

４．年金の信頼性を重視
・保険料の流用は国民の年金に対する信頼を損ない、これを即刻停止すべきと主張。

５．専業主婦家庭への優遇措置の見直しを提言
・税制や社会保障制度の見直しが必要で、特に女性の働く環境を整えることが急務であると強調。----------1. 社会保障制度の見直しに賛成
   - 社会保障は児童福祉、障害者福祉、高齢者福祉の三つに分かれており、高齢者福祉については介護保険制度を中心に考えるべきと述べている。

2. 介護保険制度に対する意見
   - 介護保険は保険料を支払うことで受給権が得られる制度であり、権利の拡大が必要であると考え、保険料の流用を停止し全額国庫負担に戻すべきと提言している。

3. 政策立案に対する要望
   - 社会保障政策の効果的な実施には精緻なデータが必要だとし、具体的な目標に向けた進捗確認の重要性を強調。

4. 専業主婦家庭に対する優遇措置の見直し
   - 社会保障制度の優遇措置は見直すべきと考えているが、女性の働く環境整備を優先課題とし、女性の社会進出促進が急務であると強調している。
