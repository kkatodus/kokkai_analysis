１．社会保障制度の見直しを支持
・現在の税や社会保障のシステムが働きたい人に過度な負担をかけており、必要な支援が届いていないと指摘。

２．労働者の負担軽減を提案
・厚生労働省の新しい仕組みは中小企業には適用されにくく、実際の負担軽減につながるのか懸念している。

３．マイナンバー活用による改革を提唱
・所得や資産の把握を早急に行い、現行の税と社会保障を統合して、給付つき税額控除を実現するべきだと主張。----------1. 日本の税や社会保障システムの一部見直しを提案
   - 働きたい人に過剰な負担をかけている現状を問題視し、本当に困っている人に適切な支援が届いていないと指摘。

2. 中小事業者への配慮が必要
   - 社会保険料の負担が中小企業にとって大きな問題であり、この新しい仕組みが実際に受け入れられるか疑問を呈している。

3. マイナンバー活用による効率的な支援の必要性
   - 真に支援を必要とする人々に迅速に支援が届くよう、所得や資産の把握を制度化し、改革を進めるべきとの考えを示す。

4. 税と社会保障の統合改革を提唱
   - 給付つき税額控除の実現を目指し、税制全体の抜本的な見直しを求めている。----------1. 社会保障システムの見直しを支持
   ・現在の税や社会保障が、働く意欲のある人々に対して重い負担を課し、真に困っている人々への支援が不十分であると指摘。

2. 中小事業者の負担軽減を重視
   ・社会保険料の事業者負担が中小企業にとって厳しい問題であるため、労働者負担を軽減する仕組みの導入が必要だと述べる。

3. マイナンバー活用による改革を提案
   ・真に支援が必要な人々に早急に支援を届けるために、所得や資産の把握をマイナンバーで行い、税と社会保障の統合改革を進めるべきと主張。

4. 給付つき税額控除の実現を重要視
   ・社会保障と税の一体改革を進める中で、低所得者対策としての給付つき税額控除の導入が必要であるという認識を示す。
