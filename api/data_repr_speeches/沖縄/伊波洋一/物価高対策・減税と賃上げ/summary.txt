1. 賃上げを出発点とするべき
   - 労働生産性を前提にせず、まず賃上げを行うことが重要と主張。最低賃金を引き上げることに重点を置いている。

2. 中小企業への支援が必要
   - 最低賃金の引き上げによる影響を受ける中小企業への無利子融資や損失補填などの支援策を提案。これにより、中小企業が賃上げに対応できるようにする必要性を強調。

3. 労働生産性の考え方の見直し
   - 労働生産性の向上を前提とした賃上げではなく、賃上げが経済成長に寄与するという新たな視点を提示。賃上げによる個人消費の活性化が経済の好循環につながると説明。

4. 最低賃金の目標設定
   - 政府が2020年の方針で掲げた最低賃金全国加重平均千円を早期に実現するための具体策を求めている。----------1. 賃上げを重視
   - 労働生産性を前提とせず、賃上げを出発点とする重要性を強調。最低賃金の引き上げを提案。

2. 中小企業への支援を求める
   - 最低賃金引き上げに影響を受ける中小企業には、無利子融資や損失補填などの政策で支援すべきと主張。

3. 個人消費の促進を目指す
   - 賃上げが商品価格に反映され、その結果として個人消費が活性化する好循環が経済成長につながるという見解を示す。

4. 最低賃金の目標設定
   - 最低賃金を全国加重平均千円にするための具体的な実現策を政府に質問し、政策の透明性を求める。----------１．賃上げを重要視
・賃上げを経済成長の出発点とし、まず賃金を引き上げるべきだと主張。

２．最低賃金の引き上げを提唱
・最低賃金を上げることで、営業利益に影響を受ける中小企業の支援策を検討すべきと提案。

３．労働生産性を賃上げの前提条件としない 
・労働生産性の向上を賃上げの条件とする考え方を見直し、賃上げ自体が経済成長を促進すると強調。

４．好循環の実現を目指す
・賃上げが商品の価格に影響し、その結果として個人消費が活性化する経済サイクルを重視。

５．政府の対応に疑問
・最低賃金千円の実現に向けた具体的な方策について、政府の説明を求める姿勢を見せる。
