1. 消費税廃止を強く主張
   - 内需拡大のためには消費税を廃止するしかないと論じ、消費税が財源に縛られている現行制度の問題を指摘。

2. 大企業や資本家からの税収増を提案
   - 消費税に依存するのではなく、国債発行や法人税の累進課税を通じて資本家から適切に税収を得るべきだと主張。

3. 賃上げに対する明確な政策提案
   - 労働者の取り分を高める政策や公的部門の大幅賃上げが必要であり、政府が積極的に賃上げを促進するべきと述べる。

4. 緊急の経済対策が必要と強調
   - 物価上昇に対抗するため、賃上げ目標の設定や政府主導の賃上げを求め、政府が適切な対応をしないことを批判。

5. 消費税減税の実現を求める
   - 現状の経済や物価の状況から考えて、消費税を即座にゼロにするべきだと強調し、他の減税措置の必要性も訴える。----------1. 消費税の廃止を強く主張
・内需拡大のためには消費税を廃止するしかないと指摘。消費税収は庶民から取り、法人税が下がる現状を批判。

2. 賃上げの必要性を強調
・賃上げは生産性向上ではなく、労働者の取り分を増やす政策が必要と主張。公的部門の賃上げと人員増を提案している。

3. 財源の確保についての提案
・財源を消費税に頼らず、国債発行や資本家からの税収増を求めている。

4. 現政権に対する批判
・岸田内閣が消費税減税や賃上げを行わず、財政規律にとらわれていることを批判。緊急の経済対策の必要性を訴えている。

5. マクロ経済政策の必要性
・消費税の減税やガソリン税の廃止を通じて、所得を増やし、個人消費を支えることが重要と強調している。----------1. 消費税廃止を強く主張
   - 内需拡大のためには消費税を廃止し、国債発行や資本家からの税収で代替するべきという立場。

2. 減税と賃上げの必要性を強調
   -物価上昇に対抗するために、賃上げを促進し、特に公的部門の大幅賃上げを実施することが必要であると主張。

3. 財政規律への疑問
   - 現政権が財政規律に縛られすぎており、国民のために減税や賃上げを行うべきだと批判。

4. 賃上げ目標の設定を提案
   - 政府がダイレクトに賃上げ目標を掲げ、労働者の取り分を増やす政策を進めるべきと述べる。

5. 物価上昇に対する政府の対応の不備を指摘
   - 現在の賃金が物価上昇に追いついておらず、政府の対応が不十分であると強く非難。
